# W@niPoem - Landing Page

A landing page for W@niPoem, a poetry school and community where people can read poems, share their own verses, and get kind feedback from other writers.

This project is part of The Odin Project Foundations course (HTML & CSS). The layout follows the project's design mockup, with all the text and images replaced to fit a poetry theme.

## Live Demo
[view the site](https://rezuana24-git.github.io/odin-landing-page/)


## Features
- Header with logo and navigation links
- Hero section with a title, short description, call-to-action button, and logo image
"Why poetry lovers choose W@niPoem" section with four image cards
- Testimonial section with a long quote and the author's name aligned to the right
- Call-to-action box with a sign-up button
- Footer with copyright notice.
## Built With
- HTML5 (semantic tags: header, nav, section, figure, footer)
- CSS3 (Flexbox, custom colors, object-fit, border radius)
- Roboto font from Google Fonts
## What I Practiced
Structuring a full web page with semantic HTML
Using Flexbox to align the header, hero, image cards, and call-to-action
Resetting default browser styles with margin: 0, padding: 0, and box-sizing: border-box
Keeping images the same size with object-fit: cover
Aligning text (the quote author) to the right with text-align
Using Chrome DevTools to find and fix layout problems
## Note
This website is designed for desktop screens only. It is not responsive, so the layout may look broken on tablets and phones.
